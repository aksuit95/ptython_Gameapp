# Python Game App

Python으로 만드는 게임 앱 프로젝트입니다. 구현 전에 요구사항을 문서화하고, 그 문서를 기준으로 기능을 추가합니다.

## 문서

| 문서 | 용도 |
| --- | --- |
| [docs/요구사항명세서.md](docs/요구사항명세서.md) | 작성 중인 요구사항명세서 본문 |
| [docs/templates/요구사항명세서_템플릿.md](docs/templates/요구사항명세서_템플릿.md) | 새 명세를 시작할 때 복사하는 빈 양식 |
| [docs/요구사항_작성가이드.md](docs/요구사항_작성가이드.md) | ID 규칙, 작성 순서, 완료 기준 |

## 요구사항 작성 순서

1. `docs/요구사항명세서.md`를 연다.
2. 1장 개요(목적, 범위, 사용자)를 채운다.
3. 기능 요구사항은 `FR-001`부터 한 항목씩 추가한다.
4. 비기능 요구사항은 `NFR-001`부터 추가한다.
5. 각 항목의 상태(`초안` / `확정` / `보류`)를 갱신한다.
6. 작성가이드의 점검 목록을 통과하면 구현을 시작한다.

## 디렉터리

```text
docs/
  요구사항명세서.md
  요구사항_작성가이드.md
  templates/
    요구사항명세서_템플릿.md
```

게임 코드는 요구사항이 확정된 뒤에 `src/`에 둡니다.
